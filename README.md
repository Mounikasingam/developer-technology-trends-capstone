## Project Overview

This project was completed as part of the IBM Data Analyst Professional Certificate Capstone Project. It explores developer technology trends using survey data and job-posting information.

## Objectives

- Analyze popular programming languages and emerging technologies.
- Explore current and future database preferences.
- Examine cloud platforms and web frameworks.
- Analyze developer demographics and job-posting locations.
- Present findings through visualizations and dashboards.

## Tools and Technologies

- Python
- Pandas
- IBM Cognos Analytics
- Data Cleaning and Exploratory Data Analysis
- Data Visualization

## Key Findings

- JavaScript, SQL, and HTML/CSS are among the leading programming languages in current usage.
- PostgreSQL is a leading database in the analysis.
- Go and Rust show strong future interest.
- AWS is a prominent cloud platform.
- The project examines developer demographics and job-posting trends.
